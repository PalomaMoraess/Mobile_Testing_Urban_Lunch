# Testes Mobile - Urban Lunch

## 📖 Sobre o projeto

Este repositório reúne as atividades desenvolvidas durante o projeto de testes mobile da formação em **Quality Assurance** da **TripleTen**.

O objetivo foi validar as funcionalidades do aplicativo **Urban Lunch**, executando testes manuais em um dispositivo Android virtual (emulador), identificando falhas e registrando os resultados obtidos.

---

## 🎯 Atividades realizadas

- Análise dos requisitos da aplicação.
- Elaboração de checklist de testes.
- Execução de testes funcionais em aplicativo Android.
- Identificação e documentação de bugs.
- Validação da interface e do fluxo de navegação.

---

## 🛠️ Ferramentas utilizadas

- Android Emulator
- Android Studio
- Jira
- Google Sheets
- Figma

---

## 📂 Conteúdo do repositório

- `Checklist_Testes_Urban_Lunch.xlsx` — Checklist de testes executados e resultados obtidos durante a validação do aplicativo.

---

## 📱 Funcionalidades testadas

- Seleção do ponto de coleta.
- Escolha dos pratos.
- Confirmação do pedido.
- Tela de acompanhamento.
- Entrega do pedido.
- Mensagens de erro.
- Validação de layout e interface.

---

## 🧠 Habilidades desenvolvidas

Durante este projeto desenvolvi habilidades relacionadas à elaboração de checklists, execução de testes manuais em aplicações mobile, identificação de defeitos, validação de interface, análise de requisitos e documentação de bugs.
